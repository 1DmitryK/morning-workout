# Pulse Transcript — Whisper Large-v3 Turbo на Mac M2

Это **опциональный локальный движок**. Он не запускается на GitHub Pages и ещё не испытывался непосредственно на Mac пользователя.

## Установка (Mac с Apple Silicon)
1. Скачай весь репозиторий как ZIP: https://github.com/1DmitryK/morning-workout/archive/refs/heads/main.zip
2. Распакуй ZIP, открой \`morning-workout-main/pulse-transcript/mac-bridge\`.
3. В Terminal проверь наличие Python 3 и FFmpeg:
   \`\`\`sh
   python3 --version
   ffmpeg -version
   \`\`\`
   Если FFmpeg нет, установи через Homebrew: \`brew install ffmpeg\`.
4. В Terminal выполни:
   \`\`\`sh
   cd /путь/к/morning-workout-main/pulse-transcript/mac-bridge
   zsh start.command
   \`\`\`
   Можно также перетащить папку \`mac-bridge\` в окно Terminal после \`cd \` и нажать Enter.
5. Дождись вывода адреса вида \`http://localhost:8765/?token=...\`. Открой **именно его**, а не GitHub Pages.
6. В поле «Модель распознавания» выбери «Mac · Large-v3 Turbo»; после первого запуска модель (~1.6 ГБ) загружается из Hugging Face. Повторно скачивать её не нужно.

## iPad через Mac
В доверенной домашней Wi-Fi сети (не в общественной!) введи в Terminal:
\`\`\`sh
PULSE_SHARE_IPAD=1 zsh start.command
\`\`\`
В Terminal появится специальный локальный URL с секретным ключом для iPad. Открой его в Safari на iPad; запись будет отправлена **на собственный Mac в твоей сети**, а не на GitHub. Mac должен работать всё время.

**Ограничения приватности:** LAN-версия использует HTTP без шифрования. Не открывай её в публичной Wi-Fi сети; не пересылай URL с токеном. Для полностью защищённой передачи по сети понадобится HTTPS с локально доверенным сертификатом или VPN. По умолчанию сервер слушает только \`127.0.0.1\`.

## Как работает
- Сервер принимает запись и сохраняет во временный файл на Mac.
- FFmpeg декодирует всю аудиодорожку в 16 кГц моно.
- \`mlx-whisper\` использует \`mlx-community/whisper-large-v3-turbo\` и обрабатывает длинную запись целиком с собственными сегментами и временными метками.
- Для украинского задаётся словарь имён в \`initial_prompt\`, а передача предыдущего текста в следующий фрагмент выключена, чтобы уменьшить риск зацикливания.
- После завершения временные файлы удаляются. Результат сохраняется только в браузере, как в старой версии.

## Возможные ошибки
- \`python3\` не найден: установи современный Python 3 для macOS.
- \`ffmpeg\` не найден: \`brew install ffmpeg\`.
- Ошибка импорта MLX: убедись, что Python выполняется на Apple Silicon (arm64), а не через Rosetta; запусти \`uname -m\`.
- Порт 8765 занят: \`PULSE_PORT=8777 zsh start.command\`.
- При работе на iPad вкладка GitHub Pages не видит Mac-движок: открывай URL Mac, показанный в Terminal.

Код размещён в папке \`mac-bridge/\`. Проверка качества на реальном Mac и долгих аудиофайлах — отдельный необходимый этап.


## Шаг 3: исправление текста (по желанию)
Эта функция — **отдельный черновик**, а не замена оригинальной записи.
1. Установи Ollama для macOS: https://ollama.com/download/mac
2. В Terminal один раз выполни: \`ollama pull qwen3:4b\`.
3. Убедись, что Ollama запущена и доступна по \`http://127.0.0.1:11434\`.
4. В Pulse Transcript после распознавания нажми \`Исправить текст на Mac\`.
5. Появится отдельная вкладка \`Исправлено\`. Сравни результат с исходной вкладкой \`Транскрипция\` и аудио, прежде чем цитировать речь. Перевод английского берёт исправленный вариант, если он создан.

Не требуется устанавливать Ollama, если нужна только транскрипция. При 16 ГБ памяти одновременная работа двух моделей может увеличить время обработки или вызвать нехватку памяти. Если это случится, сначала сохрани расшифровку, затем закрой тяжёлые программы и запусти коррекцию повторно.

## Ограничения текущей версии
- В браузере на iPad по-прежнему доступен Whisper Tiny/Base/Small; Large-v3 Turbo работает **только через запущенный Mac-сервер**.
- В HTML-версии на GitHub Pages нельзя выбрать локальный Mac-движок напрямую — открой адрес \`localhost:8765\` или частный URL Mac для iPad.
- Сервер показывает ход загрузки и подготовки, но при самом MLX-распознавании не может показывать точную поминутную шкалу; надпись «Whisper Large-v3 Turbo» может отображаться долго.
- Коррекция Ollama — вероятностная; не стоит считать её дословной записью речи.
- Реальное качество на Mac M2 и iPad в режиме подключения к Mac нужно проверить на твоих исходных аудиозаписях.
