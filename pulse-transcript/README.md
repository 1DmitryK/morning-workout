# Pulse Transcript

Одно HTML-приложение с четырьмя этапами работы: **аудио → распознавание → проверка → перевод**.

## 1. iPad и веб-версия (без установки Mac-сервера)
Открыть: https://1dmitryk.github.io/morning-workout/pulse-transcript/

- Работает в Safari на iPad и Mac через Transformers.js.
- Whisper Tiny / Base / Small; Small по умолчанию.
- Местная конвертация M4A/MP4 в WAV (FFmpeg.wasm), если браузер видит неполную дорожку.
- Перекрытие аудиофрагментов и дополнительная попытка при обнаружении повторяющегося текста.
- Текст с временными метками, подсветка сомнительных фрагментов, редактирование, TXT/SRT/DOCX.
- Отдельный перевод **только с английского на русский или украинский** (OPUS-MT).
- Распознанное аудио не отправляется в GitHub или внешние облачные сервисы.

**Ограничения:** iPad ограничен памятью и скоростью браузера; ошибки Whisper Base/Small всё равно возможны. Автоповтор не гарантирует устранение зацикливания. Веб-версия не включает Large-v3 Turbo.

## 2. Mac M2 / M-series: Whisper Large-v3 Turbo
Исходники и инструкции: [mac-bridge/README_RU.md](mac-bridge/README_RU.md)

- Модель: \`mlx-community/whisper-large-v3-turbo\`, для Apple Silicon.
- Локальный Python-сервер и FFmpeg, запись полностью обрабатывается Mac.
- На Mac приложение открывается по частному адресу \`http://localhost:8765/?token=...\`, который печатается в Terminal. **Это другой URL, не GitHub Pages.**
- При желании iPad может открыть частный URL Mac в одной доверенной Wi-Fi сети, чтобы использовать мощную модель на Mac.
- На Mac будет доступен режим **Mac · Whisper Large-v3 Turbo**.
- Результат сохраняется после успешного завершения, не стирая прежнюю транскрипцию при сбое.

## 3. Исправленная версия
- Дополнительная кнопка **Исправить текст на Mac** через Ollama + \`qwen3:4b\` (другая локальная модель, требует отдельной установки).
- Отдельная вкладка **Исправлено**. Оригинал всегда остаётся в **Транскрипция**.
- Исправления могут быть ошибочными. Не выдавать результат модели за проверенную дословную цитату без сравнения со звуком.
- Если есть исправленный английский текст, перевод использует его; иначе исходный.
