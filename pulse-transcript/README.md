# Pulse Transcript — браузерная версия (v0.1)

Личный статический сайт, работающий на GitHub Pages в Safari/Chrome на Mac и iPad. Ни сервера, ни API-ключа не требуется.

## Что делает
- Импорт M4A, MP3, WAV и других форматов, которые поддерживает установленный браузер.
- Whisper Tiny/Base (multilingual), распознавание русского, украинского и английского.
- Перевод **только английского** текста на русский или украинский при помощи локальных моделей OPUS-MT.
- Последовательная обработка 25-секундными фрагментами, приблизительные временные метки.
- Редактирование, копирование, экспорт TXT/SRT/DOCX. Автосохранение текста в localStorage.

## Ограничения
- Первое использование требует скачивания больших AI-моделей с Hugging Face. Для самой веб-страницы также нужен CDN с Transformers.js. «Офлайн» относится к инференсу после загрузки и доступности ресурсов из браузерного кеша, но не обещает полный автономный запуск при первом открытии.
- Вся аудиозапись сначала декодируется браузером целиком: для длинных файлов нужен значительный объём RAM; Safari на iPad может выгрузить вкладку. У программы нет серверного лимита 30 минут, но аппаратные ограничения остаются.
- WebGPU может не работать на некоторых устройствах, тогда используется медленный WASM/CPU. Проверка на реальных устройствах ещё необходима.
- 25-секундная разбивка без перекрытия может терять части слов на границах. Временные метки указывают приблизительное начало отрезка, не таймкод каждого слова.
- Термины, имена и цитаты обязательно сверять вручную.
- Перевод доступен для английского исходного текста, не для русского↔украинского.
- Известны сообщения о чрезмерном расходе GPU-памяти некоторыми комбинациями Whisper + Transformers.js; длинный файл может потребовать обработки в Mac-приложении вместо браузера.
- Под капотом используются Transformers.js 3.8.1, Whisper ONNX (onnx-community/whisper-tiny/base), OPUS-MT (Xenova/opus-mt-en-ru и -en-uk) и fflate для DOCX.

## Запуск
Открой GitHub Pages URL для директории `pulse-transcript/` или файл `index.html` на статическом HTTPS-хостинге. Чтобы добавить на iPad: Safari → Поделиться → На экран «Домой».

Приложение не отправляет выбранное аудио в облако: модели загружаются отдельно из CDN/Hugging Face и выполняются в браузере. Текст сохраняется локально в памяти браузера. GitHub Pages — публичный хостинг исходного кода; сама запись в репозиторий не загружается.
