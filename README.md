# Моя зарядка

Мобильное приложение без сборки: анимации четырёх упражнений, общий таймер занятия, дневник подходов, напоминание на открытой странице и экспорт ежедневного события в календарь.

## Открыть как приложение

Разместите корень репозитория на GitHub Pages. В Safari откройте адрес сайта, затем «Поделиться» → «На экран Домой» → «Открывать как веб-приложение», если переключатель показан → «Добавить».

Отметки сохраняются только в браузере этого устройства; между устройствами нет синхронизации. После первой успешной загрузки service worker сохраняет приложение для работы без интернета. В закрытом приложении собственные уведомления не отправляются: используйте системный календарь или «Напоминания».

## Библиотека упражнений

- Подъём на носки с опорой.
- Равновесие с рукой на опоре.
- «Работа пальчиками»: движения стоп на себя и от себя сидя, по описанию пользователя.
- Пресс: небольшой подъём головы и груди лёжа с согнутыми коленями (abdominal crunch).

Анимации схематичны и не являются персональной программой реабилитации. Темп показа не задаёт обязательный темп выполнения. Количество повторений нового упражнения на пресс не назначено.

### Источник для пресса

Royal Berkshire NHS Foundation Trust, *Core exercise programme*, reviewed May 2025, exercise 4, page 2:
https://www.royalberkshire.nhs.uk/media/qfljlxzd/physio-core-exercise-programme-matplusgynae.pdf

Текст инструкций пересказан по-русски; рисунки созданы самостоятельно. В исходной памятке рекомендовано выполнять упражнения, согласованные с физиотерапевтом.

## Как добавлять упражнения

1. Добавьте запись в `exercises.js` со стабильным `id`, названием, положением, описанием, источником и именем позы.
2. Добавьте соответствующий рисунок движения в `drawPose()` в `app.js`.
3. Обновите версию кэша в `sw.js`.
4. Запустите `node tests/app.test.cjs` и проверьте приложение в браузере.

## Структура

- `index.html`, `style.css` — интерфейс.
- `exercises.js` — реестр упражнений.
- `app.js` — анимации, таймер и дневник.
- `manifest.webmanifest`, `sw.js`, `assets/` — установка и автономная работа.

Персональные сведения пользователя и его медицинская история в репозиторий не включены.
